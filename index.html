1. Introdução do Trabalho

A criptografia é uma forma de proteger informações utilizando modelos matemáticos. Ela transforma os dados originais em informações codificadas, que só podem ser acessadas corretamente por quem possui a chave adequada.

Contextualização

A criptografia é usada para proteger dispositivos, para proteger transações financeiras, e para garantir que mensagens com informações pessoais são particulares.

Objetivo

O principal objetivo deste trabalho foi analisar a aplicação da teoria dos números na criptografia, com foco no algoritmo RSA, demonstrando a aplicação prática de conceitos de Matemática através de códigos de programação para resolver um problema real de inovação.
